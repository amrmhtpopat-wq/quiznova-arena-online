# QuizNova Arena V10.3 — الأمان والاستقرار (نسخة تجريبية)

## ما تم تنفيذه
- تغيير كلمة المرور من لوحة المعلم مع إبطال الجلسات القديمة.
- استعادة كلمة المرور برمز سري صالح لمدة 20 دقيقة ولمرة واحدة، **لكن إرسال البريد غير مفعّل حتى تهيئة SMTP بصورة آمنة**.
- نسخ احتياطية على مستوى حساب المعلم (الأسئلة والطلاب والجلسات والمحاولات)، حتى 14 نسخة، مع نسخة إنقاذ قبل الاسترجاع. تتولد نسخ تلقائيًا عند النشاط.
- مزامنة نسخة المعلم حسب رقم مراجعة؛ تعديل جهاز قديم لا يكتب فوق تعديل جهاز آخر بصمت. تحفظ مسودة محلية عند تعارض البيانات.
- ترويسات حماية HTTP، وتقييد محاولات الدخول بصورة لا تضر المعلمين خلف نفس الشبكة.
- الحفاظ على خاصية الغرف المباشرة و QR وشخصيات الطلاب والإعدادات الحالية.

## نتائج الاختبارات
- 43 اختبارًا محليًا لواجهات API والخادم، منها 50 طالبًا يدخلون غرفة واحدة بالتوازي؛ لا توجد ضمانات لنتائج الإنترنت من هذا الاختبار المحلي.
- فحص بناء Python و JavaScript بنجاح.
- يجب اختبار PostgreSQL السحابي من خدمة تجريبية قبل ترقية V10.2.

## ما لا يزال مشروطًا
- قاعدة الاختبار Neon: quiznova_v103_stage (منفصلة عن قاعدة المستخدمين الأصلية). ربط DATABASE_URL في Render لم يُكمل بعد.
- خدمة Render sandbox تستخدم SQLite مؤقتة، لذا **لا تسجل عليها بيانات مدرسية حقيقية**.
- لتشغيل البريد: أضف SMTP_HOST وSMTP_PORT وSMTP_USER وSMTP_PASSWORD وSMTP_FROM وQUIZNOVA_PUBLIC_URL إلى متغيرات خدمة Render، ولا ترفع الأسرار إلى GitHub.
- النسخ المحفوظة داخل قاعدة البيانات ليست بديلاً عن نسخة خارجية مستقلة أو نسخ Neon الدورية. 
- يلزم اختبار مجموعة معلمين متزامنين و50 طالبًا على الاستضافة الحقيقية، ومراجعة أمان مستقلة قبل إطلاق عام.
