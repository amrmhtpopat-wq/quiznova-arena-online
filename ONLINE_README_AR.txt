QuizNova Arena Online V6
========================
هذه النسخة معدّة للنشر على الإنترنت كخدمة Web واحدة.

بعد النشر:
- رابط المعلم: https://YOUR-SERVICE.onrender.com/
- رابط الطلاب: https://YOUR-SERVICE.onrender.com/student.html
- لا يحتاج الطلاب أن يكونوا على نفس الشبكة.
- عند إنشاء غرفة يظهر QR عام + PIN من 6 أرقام.
- QR يفتح رابط الغرفة ويعبئ PIN تلقائيًا.
- المعلم يمتلك مفتاح تحكم سريًا للجلسة لا يصل إلى الطالب.

نشر سريع على Render:
1) أنشئ مستودع GitHub جديدًا (مثلاً quiznova-arena-online).
2) ارفع محتويات هذا المجلد إلى جذر المستودع.
3) في Render اختر New > Web Service واربط المستودع.
4) Runtime: Python
5) Build Command: python --version
6) Start Command: python server.py
7) Plan: Free للتجربة أو خطة مدفوعة إذا أردت تشغيلًا أسرع وأكثر ثباتًا.
8) Health Check Path: /api/health

ملاحظات:
- الغرف الحية تحفظ في ذاكرة الخادم أثناء الجلسة وتزال تلقائيًا بعد 8 ساعات.
- في الخطة المجانية قد يستغرق أول فتح بعد فترة خمول وقتًا قصيرًا حتى تستيقظ الخدمة.
- أثناء وجود الطلاب والجلسة نشطة تبقى الخدمة مستقبلة للطلبات.
- الاختبارات وبنك الأسئلة الدائم محفوظة في متصفح جهاز المعلم (LocalStorage) مثل النسخة الحالية.
